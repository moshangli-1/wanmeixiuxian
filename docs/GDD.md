# 《完美修仙》游戏设计文档（GDD）

> 读者：制作人（第 1–4 节）、工程师（第 4–6 节）、策划/QA（第 5–7 节）。
> 数值细节与公式推导见 [`数值与公式.md`](./数值与公式.md)，本文不重复。

---

## 1. 一句话定位

凡人少年逆天改命：从炼气一层的无名散修开始，**挂机吐纳、斗法夺宝、奇遇问心**，历经九大境界，最终渡劫飞升、轮回再启的**修仙文字放置游戏**。

## 2. 幻想内核与目标玩家

| 项 | 定义 |
|---|---|
| 幻想（Fantasy） | 「大道争锋，我命由我不由天」——每一段文字都在讲述"我"的修行 |
| 目标玩家 | 中文放置/文字游戏玩家；通勤、课间、睡前打开，单次 1–5 分钟，每日 3–8 次 |
| 平台 | Web（浏览器即开即玩）、Windows/macOS 桌面端（Electron）、Android（Capacitor） |
| 会话长度 | 秒级反馈（数字增长）＋ 分钟级决策（探索/炼丹/突破）＋ 天级节奏（大境界/日常/轮回） |
| 成功信号 | 玩家第 1 天能完成：注册→修炼至炼气三层→首次探索→首次突破；7 日留存看点为大关突破与天道榜 |

## 3. 设计支柱（按优先级排序）

1. **修行不止** — 任何时刻离线都在积累，回来必有可领取的进展；绝不惩罚离线玩家。
2. **文字演武** — 每场战斗、每次奇遇都是一段有画面感的叙事文字，"读战斗"本身就是核心体验。
3. **境界跃迁的仪式感** — 突破是全游戏最大的爽点：有失败风险、有特效、有质变（新地图/新玩法解锁）。
4. **轮回再启** — 飞升不是终点：道韵永久加成构成多周目 meta 循环。

## 4. 核心循环

**一句话**：挂机积攒灵气 → 灵气满冲击突破 → 新境界解锁更强功法/更凶妖兽/更好掉落 → 修炼速度提升 → 继续积攒。

| 层级 | 周期 | 玩家行为 | 奖励节奏 |
|---|---|---|---|
| 即时循环 | 秒 | 观察灵气增长、粒子飞升 | 数字持续跳动 |
| 会话循环 | 1–5 分钟 | 探索斗法、炼丹炼器、处理奇遇、突破 | 每次操作必有产出或叙事 |
| Meta 循环 | 天 | 大境界突破、宗门日常、天道榜、轮回 | 大关仪式感 + 社会比较 |

**张力来源**：突破失败的反噬风险（亏 30% 灵气）＋ 奇遇选择的后果不确定 ＋ 天道榜排名比较。三者 protected：突破成功率有下限（≥45%），奇遇每个选项必有定义结局，榜单按境界分层可见。

**精通后的循环演化**：同一套规则在高境界通过「大关概率惩罚（九层 -15%）」「天劫试炼」「炼器随机词缀」提供新的决策深度，而不是纯数字膨胀。

## 5. 系统地图

```
                    ┌──────────────┐
        灵石/材料 ──▶│  炼制(丹/器)  │──▶ 丹药/法宝 ─┐
        │           └──────────────┘              ▼
┌───────┴────────┐   ┌──────────┐   ┌─────────────────────┐
│  斗法(探索副本)  │──▶│  行囊/装备 │──▶│      角色属性        │
│  掉落灵石/材料   │   └──────────┘   │  攻/防/血/灵气速率   │
└───────┬────────┘   ┌──────────┘   └──────────┬──────────┘
        │            │                         │
        ▼            ▼                         ▼
┌──────────────┐ ┌──────────┐   灵气  ┌────────────────────┐
│ 奇遇(随机事件) │ │ 功法/宗门  │───────▶│  境界突破(9境×9层)  │
│  选择→结局     │ └──────────┘         └──────────┬─────────┘
└──────────────┘                                  │ 渡劫九层圆满
                     ┌──────────┐                 ▼
                     │  天道榜   │         ┌──────────────┐
                     └──────────┘         │ 轮回飞升(道韵) │──▶ 新周目
                                          └──────────────┘
```

系统间触达同一数值时的**结算顺序**（全游戏统一）：
`基础值 → 功法加成 → 宗门加成 → 道韵加成 → 装备加成 → 取整`。

## 6. 内容规划（v1 / 本仓库交付范围）

| 内容 | 数量 | 说明 |
|---|---|---|
| 境界 | 9 境 × 9 层 | 炼气→筑基→金丹→元婴→化神→炼虚→合体→大乘→渡劫；渡劫九层圆满可渡天劫飞升 |
| 探索地图 | 18 | 每境界 2 张，怪物与掉落随境界缩放 |
| 妖兽 | 36+ | 模板化生成：每地图 2 种，数值由公式给出 |
| 物品 | 8 消耗品/材料 + 法宝 | 灵草/灵矿/妖丹/聚气丹/回春丹/破境丹等 |
| 功法 | 5 | 吐纳诀(初始)→玄阳功→太虚剑意→混元一气功→大罗仙典 |
| 奇遇 | 12 | 每个奇遇 2–3 个选项，每个选项的结局表完全定义 |
| 宗门 | 4 | 剑宗/丹鼎门/御灵宗/天机阁，各一个永久被动 + 日常 + 贡献商店 |
| 炼制配方 | 3 丹 + 1 器 | 成功率与材料消耗全部入表 |

## 7. 里程碑意图

- **M1（本仓库）**：核心循环闭环可玩 —— 认证、挂机、突破、斗法、炼制、功法、奇遇、宗门、天道榜、轮回、桌面/安卓封装。
- **M2**：社交深化 —— 宗门多人、道友互动、赛季榜单。
- **M3**：长线运营 —— 限时活动、秘境副本、飞升后玩法（仙界地图）。
