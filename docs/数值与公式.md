# 《完美修仙》数值与公式

> 读者：工程师（实现与校验）、分析师（复算）。所有数值的唯一权威来源是 `server/config/content.js`，
> 本文档给出其符号形式、推导与算例；两者不一致时以配置文件为准并回报为缺陷。
> 数值来源标注：**[G]** 给定（策划拍板） / **[D]** 由公式推导 / **[O]** 开放待验证。

## 1. 境界与灵气需求

9 大境界 `r = 0..8`（炼气→渡劫），每境 9 层 `n = 1..9`。

```
灵气需求  qiNeed(r, n) = round(100 × 8^r × 1.5^(n−1))          [G: 基数100, 境界×8, 层×1.5]
```

算例：炼气一层 = 100×1×1 = **100**；炼气九层 = 100×1.5⁸ ≈ **2563**；筑基一层 = 100×8 = **800**；渡劫九层 = 100×8⁸×1.5⁸ ≈ **4.30×10¹⁰**。

## 2. 灵气速率（挂机核心）

```
qiRate = 3 × 6^r × (1 + techRate) × (1 + sectRate) × (1 + 0.05×道韵) + 装备灵气加成   [G: 3/s 基速]
techRate = Σ(已装备功法基础速率加成 × (1 + 0.1×(功法等级−1)))                          [D]
离线结算：离线收益 = qiRate × min(离线秒数, 43200)   （离线上限 12h）                  [G]
```

节奏验证：炼气一层 100/3 ≈ 33 秒满（首次爽点 <1 分钟）；筑基一层 800/(3×6×1.5) ≈ 30 秒起，随功法/丹药加速；
渡劫九层 ≈ 4.3×10¹⁰ / (3×6⁸×~3.5) ≈ 1.2 小时/层（大关节奏）**[O]**。属性成长(×2.2/境)慢于速率成长(×6/境)，保证后期"碾压感"。

## 3. 角色属性

结算顺序：`基础 → 功法 → 宗门 → 道韵 → 装备 → 取整`（全游戏统一）。

```
缩放     scale(r,n) = 2.2^r × (1 + 0.12×(n−1))                        [G: ×2.2/境]
攻击     ATK = round(18 × scale × (1+techAtk) × (1+sectAtk) × (1+0.03×道韵) + 装备攻击)
防御     DEF = round(6  × scale + 装备防御)
气血     HP  = round(160× scale × (1+techHp) + 装备气血)
```

算例：炼气三层 scale = 1×1.24，ATK = round(12×1.24) = **15**，HP = **149**。

## 4. 斗法（服务端确定性模拟）

```
先手     玩家恒先手                                                   [G: 简化模型]
伤害     dmg = max(1, round(攻 × U(0.85,1.15) − 防))                  [D]
暴击     8% 概率 ×1.6                                                 [G]
回血     非战斗时 HP + 1.5%×最大气血/秒                                [G]
探索单次  最多 10 连战；HP < 15% 或战败则中止                           [G]
战败     HP=1，"重伤而归"，扣现有灵石 5%                                [G]
```

妖兽模板（按地图境界 r 缩放，同层玩家应稳定取胜于本境界第一张图）：

```
妖兽气血 = round(80 × 2.2^r)   妖兽攻击 = round(7 × 2.2^r)   妖兽防御 = round(3 × 2.2^r)   [G]
```

算例（closure 校验）：炼气一层玩家 ATK 18 / HP 160 vs 炼气图妖兽 HP 80 / ATK 7：
击杀轮数 = ⌈80/15⌉ = 6，受伤 ≈ 5×7 ≈ 35，可连战 3–4 场后按 15% 血线自动收手 ✔
（v1 数值曾取 12/120 vs 90/9，实测开荒仅能连杀 4 场即重伤，不满足"稳定取胜"目标，已修订。）

## 5. 掉落与经济（水龙头/水槽）

水龙头：探索掉落、奇遇、宗门日常；水槽：坊市购买、炼制消耗、炼器灵石费、战败折损。

```
灵石掉落/战 = round((20 + 15r) × 2.2^r × U(0.8,1.3))                            [D]
灵气掉落/战 = round(qiNeed(r,1) × 0.05 × U(0.8,1.2))                            [D]
材料掉落率   灵草 30% / 灵矿 22% / 妖丹 12% / 破境丹 2%（天机阁 +15%）             [G]
坊市价       灵草 20 / 灵矿 30 / 聚气丹 100 / 回春丹 80 / 破境丹 500 灵石         [G]
```

聚气丹效果 = 立即获得 `qiRate × 300` 灵气（等价 5 分钟挂机，避免数值膨胀）**[D]**。

## 6. 突破

```
成功率 p = clamp( 0.95 − 0.03r − (n==9 ? 0.15 : 0) + 0.15×破境丹 + min(0.15, 0.01×道韵), 0.45, 0.95 )  [G: 下限45%]
成功     层+1；第 9 层成功则 境+1 层归 1，奖励灵石 = round(500 × 8^r)        [D]
失败     灵气 ×0.7，气血降至 50%，"走火入魔"                                 [G]
消耗     每次尝试消耗灵气 = min(当前灵气, qiNeed(r,n))                       [D]
```

算例：筑基九层(大关)无丹：p = 0.95−0.03−0.15 = **0.77**；有破境丹：**0.92**。

## 7. 炼制

```
丹药成功率 = 配方基础率 × (1 + (宗门==丹鼎门 ? 0.15 : 0))                    [D]
炼器       消耗 灵矿×10 + 妖丹×5 + 200 灵石，成功率 0.6×(1+丹鼎门0.15)
法宝词缀   q = U(0.8, 1.35)；品阶 t = min(当前境界, 8)                       [G]
  武器 攻 = round(18 × 2.2^t × q)   防具 血 = round(350 × 2.2^t × q)
  灵器 防 = round(12 × 2.2^t × q), 攻 = round(5 × 2.2^t × q), 灵气速率 +0.1   [G]
```

## 8. 功法与宗门

```
功法有效加成 = 基础加成 × (1 + 0.1×(等级−1))；等级上限 = 当前境界+1            [G]
升级花费     = round(200 × 6^等级) 灵石                                       [G]（1→2 级 1200 灵石）
宗门被动     剑宗 攻+12% / 丹鼎门 炼制+15% / 御灵宗 灵气速率+15% / 天机阁 掉落+15% 且奇遇率+10%  [G]
宗门日常     打坐参禅 +40 贡献(每日1次) / 除魔卫道 击杀10 +60 贡献(每日1次)     [G]
```

## 9. 奇遇

```
触发：每次探索结束后 P = 0.22 + (天机阁 ? 0.10 : 0)，同时至多挂起 1 个           [G]
结构：每个奇遇 = {叙述, 选项[]}；每个选项 = 加权结局表 [{权重, 叙述, 效果}]      [G: 规则闭环]
效果域：灵石± / 灵气(占qiNeed百分比) / 气血% / 物品 / 功法 / 无
```

全部 12 个奇遇的结局表定义于 `server/config/content.js → ADVENTURES`，无未定义输入。

## 10. 轮回（飞升）与天道榜

```
条件：渡劫(r=8) 九层 且 灵气 ≥ qiNeed(8,9)
天劫  妖兽模板：气血 = 3×90×2.2⁸，攻击 = 1.6×9×2.2⁸                          [G]
成功   道韵 += 1 + 转世次数；境界→炼气1层1、灵气清零、灵石减半；功法/法宝/道韵保留  [G]
道韵效益 速率+5%/点，攻+3%/点，突破+1%/点(上限+15%)                         [G]
天道榜分 = r×10⁶ + n×10³ + floor(999 × qi/qiNeed)                            [D]
```
